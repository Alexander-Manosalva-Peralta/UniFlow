# 🚀 UniFlow — Landing Page Oficial

Sitio web oficial de presentación y descarga directa del archivo **APK** para **UniFlow**, el gestor académico inteligente para Android sin depender de Google Play Store.

## Características de esta Landing Page
- **Estética VisionOS Spatial**: Vidrio esmerilado arquitectónico oscuro, colores sólidos formales (sin degradados).
- **Descarga directa del APK**: Botones enlazados a `downloads/UniFlow.apk` con tamaño de 1.1 MB.
- **Simulador Interactivo de Notificaciones**: Demostración en vivo de las alertas push con sonido Web Audio y vibración háptica.
- **100% Responsivo**: Fluido en móviles, tablets y monitores de escritorio.
- **Sin dependencias pesadas**: HTML5 semántico, CSS3 moderno y Vanilla JS ultrarrápido.
